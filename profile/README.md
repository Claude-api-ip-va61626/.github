<p>第一个计价维度是并发，也就是同一时刻允许通过的连接数量。并发越高，通常价格越高，因为占用的资源更多。看报价时先确认并发上限，才知道这个数字买到了什么。不同方案在这个维度上差别很大。</p>

<p>第三个维度是占用时长，比如按月或按天算。时长计费便于预算，但如果你只用几天，整月的费用就有点浪费。问清能否按更短的周期算、能否暂停，是控制成本的一个实际抓手。</p>
